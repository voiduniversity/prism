# ⌨️ prism (BETA)
prism is a python coding practice, challenging you to type code using the most common keywords, symbols, and indentation. This project was made using customtkinter and tkinter in python. If there are any bugs, please create an issue.

## 📢 v1 Functionality
- prism includes three modes: easy, medium & hard
- local data saving
- dashboard system

## 🖋️ Upcoming Updates
- allow to change username
- allowing the use of different programming languages

## ❗️ Important Information
Currently, prism only work by being executed through a terminal or through an IDE. You will need to have python installed along with CustomTkinter, Tkinter and Pillow. You may be asked to "Trust this Publisher" when accessing it through an IDE.

You will have to run mainApp.py twice for the very first time, first to set up your username and then the second time to access it properly.
